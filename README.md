# ESP32-S3 智能桌宠

一个基于 **ESP32-S3** 的嵌入式智能桌宠项目，通过 OLED 表情显示、多种人机交互、红外通信、舵机动作、蜂鸣器以及 BLE 无线通信，实现一个具有状态反馈和互动能力的桌面宠物。

## 项目简介

本项目面向嵌入式系统综合实践，使用 ESP32-S3 作为主控，将显示、输入、无线通信、红外通信和执行机构整合到一个桌宠系统中。

桌宠能够根据用户的操作进入不同状态，并通过屏幕表情、舵机动作和声音进行反馈。同时支持多种输入方式，使桌宠不依赖单一的控制接口。

## 主要功能

- **OLED 表情显示**
  - 显示桌宠当前表情和状态信息
  - 根据不同状态切换显示内容
  - 支持睡眠、正常、害怕等状态表现

- **按键交互**
  - 支持按键操作
  - 包含消抖处理
  - 支持短按、长按等不同操作逻辑

- **旋钮交互**
  - 使用编码器进行输入
  - 可用于调节参数或触发桌宠行为

- **红外遥控**
  - 接收标准 NEC 红外协议
  - 支持通过红外遥控器控制桌宠
  - 支持红外发送功能
  - 对舵机动作期间的红外干扰进行屏蔽处理

- **舵机动作**
  - 使用双舵机模拟桌宠动作
  - 根据不同事件执行预设动作
  - 通过 ActionManager 统一管理动作状态和持续时间

- **BLE 蓝牙通信**
  - ESP32-S3 作为 BLE 外设
  - 手机等设备可以搜索并连接桌宠
  - 支持通过 BLE 接收文本指令
  - 可以根据接收到的指令控制桌宠状态和行为

- **蜂鸣器反馈**
  - 在特定事件或动作中提供声音反馈

- **状态管理**
  - 对桌宠的睡眠、正常、互动等状态进行统一管理
  - 不同状态对应不同的显示和动作反馈

## 系统工作流程

系统启动后，各硬件模块完成初始化，然后进入主循环。主循环持续读取用户输入和通信数据，并根据当前状态执行相应的行为。

```text
          ┌──────────────┐
          │   ESP32-S3   │
          └──────┬───────┘
                 │
     ┌───────────┼───────────┐
     │           │           │
   输入        通信        输出/执行
     │           │           │
 ┌───┴───┐   ┌───┴───┐   ┌───┴────┐
 │按键   │   │  BLE  │   │ OLED   │
 │编码器 │   │ 红外  │   │ 舵机   │
 │红外   │   └───────┘   │ 蜂鸣器 │
 └───────┘               └────────┘
```

典型的软件循环包括：

1. 检测按键输入；
2. 接收并解析红外信号；
3. 读取旋转编码器；
4. 处理 BLE / 串口指令；
5. 更新桌宠状态；
6. 更新舵机动作；
7. 更新 OLED 显示；
8. 输出调试信息。

## 状态与动作管理

项目使用状态变量和 `ActionManager` 对桌宠行为进行统一管理。

例如，当桌宠收到特定指令时，可以触发一个预设动作。动作管理器负责记录当前动作、开始时间和持续时间，并在动作结束后恢复正常状态。

这种设计可以避免将大量 `delay()` 堆积在主循环中，使系统能够在执行舵机动作的同时继续处理其他任务。

## 红外通信

红外通信采用 **NEC 协议**。

标准 NEC 数据帧主要由以下部分组成：

```text
[8 位地址] + [8 位地址反码] + [8 位命令] + [8 位命令反码]
```

项目可以利用多帧 NEC 数据传输较长的信息，并对接收到的数据进行解析和处理。

在舵机执行动作期间，为避免电机动作、电源波动等因素造成红外误触发，程序还设置了红外接收屏蔽机制。

## BLE 通信

ESP32-S3 作为 BLE Peripheral 工作，手机等设备可以搜索并连接桌宠。

连接后可以发送文本指令，桌宠根据指令执行相应操作，例如改变状态、触发动作或更新桌宠行为。

BLE 通信与本地按键、旋钮、红外输入共同构成多种人机交互方式。

## 项目特点

### 1. 模块化设计

不同硬件功能分别封装，主循环主要负责协调各模块运行，便于调试和后续扩展。

### 2. 多种人机交互

同时支持按键、旋钮、红外和 BLE 等输入方式，使桌宠具有更丰富的交互能力。

### 3. 非阻塞式动作管理

通过动作管理器记录动作开始时间和持续时间，减少长时间阻塞主循环的问题。

### 4. 状态驱动

桌宠的显示、动作和交互行为与当前状态相关，使软件结构更加清晰。
